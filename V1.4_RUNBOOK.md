python v14_selftest.py --out /tmp/ai_dfir_v14_selftest

## Workload identity

```bash
python workload_identity.py --events workload_identity.jsonl \
  --trust-domain corp.example --out workload_identity_analysis.json
```

Collect SPIFFE ID/SVID fingerprint, trust domain, workload/node selectors, process/container identity, issue/expiry/revocation time and transport peer evidence.

## Credential lineage

```bash
python credential_lineage.py --input credential_events.json \
  --approved-issuer https://idp.example --out credential_lineage_analysis.json
```

Do not store bearer tokens. Preserve credential/JTI/token hashes and claims, exchange parents, scopes, audience, workload binding and historical revocation.

## Temporal authority

```bash
python temporal_authority.py --policy authority_policy.json \
  --events actions.json --out temporal_authority_analysis.json
```

Authority can include time bounds, tenant/resource/purpose constraints, grants/denies, credential expiry and required approvals.

## Memory integrity

```bash
python memory_integrity_v2.py snapshot --records memory_records.json \
  --private-key memory.pem --out memory_snapshot.signed.json

python memory_integrity_v2.py analyze --events memory_events.json \
  --baseline memory_snapshot.signed.json --trusted-writer memory-service \
  --out memory_integrity_analysis.json
```

## Skill supply-chain

```bash
python skill_supply_chain.py inventory --root ./skill --out skill_manifest.json
python skill_supply_chain.py diff --approved approved.json --suspect suspect.json \
  --out skill_supply_chain_diff.json
```

The manifest includes file hashes, package Merkle root, executable files, external URLs, capability signals and sensitive identity/memory access signals.
