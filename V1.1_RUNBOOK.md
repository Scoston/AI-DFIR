# AI-DFIR v1.1 — Execution Integrity & Advanced Agent Attack Surfaces

## Objective

v1.1 hardens the forensic correctness of v1.0 and expands AI incident response
into execution layers that can be compromised even when the model, RAG corpus,
and identity provider appear healthy.

The release has two priorities:

1. **Evidence quality before evidence quantity**
2. **Execution integrity around the model**

# 4. Source-to-sink taint

Normalized event:

```json
{
  "event_id": "E1",
  "event_type": "retrieval_result",
  "actor_id": "rag-service",
  "content_sha256": "...",
  "metadata": {
    "untrusted": true
  }
}
```

Trace:

```bash
python taint_tracker.py \
  --events agentic_events.jsonl \
  --out taint_analysis.json
```

Or seed a known malicious content hash:

```bash
--seed-hash <SHA256>
```

Taint propagates only through explicit:

```text
parent_event_id
cause_event_ids
```

It does **not** propagate through `correlation_ids`.

This allows:

```text
web page
  -> RAG chunk
  -> model context
  -> memory
  -> next session
  -> tool argument
  -> network action
```

to be reconstructed without converting timestamp correlation into causal proof.

# 16. Clock-aware timeline

v1.1 timeline events can contain:

```json
{
  "timestamp_utc": "...",
  "clock_offset_ms_to_utc": -14.2,
  "clock_uncertainty_ms": 20
}
```

`timeline_builder.py` calculates an interval:

```text
timestamp - uncertainty
timestamp + uncertainty
```

When adjacent uncertainty intervals overlap, the timeline marks ordering as
ambiguous instead of claiming definitive order.

# 19. Repository hardening

New encrypted objects use:

```text
AIDFIR2
AES-256-GCM
4 MiB authenticated chunks
unique per-chunk nonce
SHA-256-bound AAD
```

This prevents the repository from buffering entire large objects into memory.

Old `AIDFIR1` objects remain readable.

Deduplicated objects also track the strongest evidence classification referencing
the content.

Example:

```text
same SHA-256
first record: internal
later record: restricted

object storage classification -> restricted
```
