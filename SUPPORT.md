# Support

Use GitHub Issues for reproducible bugs and feature requests and GitHub
Discussions for architecture, deployment, and investigation-method questions.

Before requesting help, include:

- AI-DFIR version and package SHA-256;
- operating system and Python version;
- install profile (`default`, `model`, `enterprise`, optional PDF);
- command executed;
- sanitized error output;
- whether the problem affects collection, evidence integrity, analysis, or UI.

Never attach real credentials, private keys, unredacted incident data, or
regulated information to a public issue.
