# AI-DFIR v1.5 Release Notes

v1.5 turns the existing AI-specific forensic engines into a substantially more
complete enterprise reference deployment. The emphasis is on **provable
collection, identity, custody, and operational readiness** rather than adding
isolated attack signatures.

The release contains 96 Evidence Packs and retains the complete model,
activation, runtime, agentic, representation/EvilFont, MCP, A2A, memory, skill,
identity, authority, containment, and analyst-workbench layers from prior
releases.

For release acceptance and artifact hashes, see `RELEASE_VALIDATION_V1.5.json` and `SHA256SUMS` in the GitHub release assets generated by `scripts/package_release.py`.
