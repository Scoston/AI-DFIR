# Code of Conduct

AI-DFIR is a technical security project. Contributors are expected to interact
professionally and respectfully.

Expected behavior includes constructive review, evidence-based disagreement,
respect for privacy and confidentiality, attribution of others' work, and clear
separation of demonstrated facts from hypotheses.

Unacceptable behavior includes harassment, discrimination, doxxing, publication
of credentials or private incident evidence, deliberate misrepresentation of
security findings, or using project channels to coordinate harmful activity.

Maintainers may edit or remove content, restrict participation, or escalate
serious abuse to the hosting platform. Security vulnerabilities should follow
`SECURITY.md`, not public discussion threads.
