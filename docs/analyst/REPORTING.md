# Investigator Reporting

Reports should state:

1. what happened;
2. what evidence establishes it;
3. what remains unknown;
4. what was contained;
5. what consequences escaped the AI boundary;
6. what evidence-integrity limitations apply.

Use calibrated language:

- **observed** — direct evidence;
- **supported** — conclusion gate satisfied;
- **correlated** — independent supporting evidence;
- **consistent with** — mechanism fits but attribution incomplete;
- **cannot establish** — required evidence is missing/insufficient.

Avoid claims such as "the AI decided" when the evidence only shows an
application issued an API request or when routing could have changed the model.
