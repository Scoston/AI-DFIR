# Analyst Escalation Matrix

| Condition | Recommended escalation |
|---|---|
| evidence hash/signature mismatch | evidence custodian + incident commander |
| cross-tenant access/identity finding | IAM/security architecture + privacy/legal as required |
| model/runtime integrity Level 3-4 | AI security/model platform owner |
| active malicious MCP/A2A/tool path | incident commander + application owner |
| open downstream consequence | target-system owner + incident commander |
| legal hold failure | legal/eDiscovery + evidence custodian |
| provider telemetry unavailable | provider/platform owner + risk owner |
| ambiguous high-impact attribution | independent DFIR peer reviewer |
| possible regulated-data exposure | privacy/compliance process |
