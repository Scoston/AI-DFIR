# Identity, Credentials, and Temporal Authority

Ask:

```text
WHO
used WHICH credential
with WHAT authority
on WHICH resource
for WHAT purpose
from WHEN to WHEN
under WHICH approval/delegation
at THE MOMENT OF ACTION
```

Preserve OIDC/SVID identity, token issuer/audience/subject/JTI, token exchanges,
scopes, expiry/revocation, tenant, role assumptions, policy grants/denies,
resource conditions, and approval decisions.

Current identity state is not enough; evaluate validity at the incident time.
