# Agentic Incident Response

Investigate the **execution system**, not only the model.

Preserve:

- harness and prompt assembly;
- plan/task/session/context IDs;
- RAG retrieval and source hashes;
- memory read/write/version;
- tool/MCP/A2A identity and schemas;
- browser/computer-use activity;
- workload identity and credentials;
- approvals and effective authority;
- queued/delegated work;
- target-system audit and consequences.

The agent may be healthy while RAG, memory, a skill, an MCP server, browser
session, credential, or delegated task is compromised.
