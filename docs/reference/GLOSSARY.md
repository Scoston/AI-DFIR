# Glossary

**Acquisition receipt** — signed metadata binding collection task, collector,
time, and collected artifacts.

**A2A Agent Card** — discovery metadata describing an A2A agent, interfaces,
security schemes, skills, and optionally JWS signatures.

**Evidence Pack** — machine-readable checklist of artifacts, quality thresholds,
questions, and conclusion gates for an alert/incident class.

**Effective authority** — the real privileges reachable by an actor/agent at a
specific time considering credentials, delegation, grants, denies, conditions,
and approvals.

**Human-visible representation** — independently rendered/observed form of a
document or output, distinct from machine-extracted text.

**MCP** — Model Context Protocol; tools/resources/prompts/tasks/apps and related
authorization/transport evidence are first-class investigation surfaces.

**Representation integrity** — whether different participants (human/parser/AI)
received materially equivalent information.

**Unsupported evidence** — a provider/system cannot supply the evidence class;
this state is unknown, never automatically clean.
